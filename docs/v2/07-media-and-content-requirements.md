## Required before Phase 3

### Cinematic Sequence Stage

- One approved dominant wide showreel or flagship sequence with a purpose-built poster and web preview
- One portrait cutaway crop/clip coordinated with the same sequence or clearly connected editorial story
- One smaller detail/motion crop/clip coordinated with the same sequence
- A defined static frame for all three surfaces before motion
- Source/ownership/licensing notes for every clip, including third-party footage
- Timecode/sequence metadata derived from real media rather than invented production UI
- A playback priority rule so only one hero surface moves at a time, with poster-led touch/reduced-motion states
- A composition that retains the reference's dominant/supporting scale hierarchy without copying its placeholder automotive/portrait/caustic assets
- Enough capability variety that the combined stage does not position ALI as automotive-only

### Selected Work

- Confirmed flagship ranking, independent of current array index
- Project-specific TR/EN title treatment and description for every visible item
- Confirmed role, year, tools, platform, format, and external URL
- Evidence notes: editorial problem, ALI’s contribution, and concrete observable technique; outcomes only if verifiable
- Approved poster crop at each expected aspect ratio and optimized preview video
- At least one credible example for each capability the page emphasizes, or narrower capability copy

### About, Experiments, Contact

- Approved real portrait or explicit approval to use the current identity image
- Final About copy in TR/EN with no unsupported client implications
- Decision on NoteZ naming and secondary placement
- Verification of `contact@nosther.site`, YouTube, GitHub, LinkedIn, and NoteZ links
- Updated OG image if the V2 visual system changes the brand presentation materially

## Content data changes anticipated in Phase 1

Project data should gain explicit editorial fields rather than overloading one generic description. Candidate fields: localized display title, original title, localized summary, contribution, evidence/techniques, media role, featured rank, and disclosure. The exact schema decision belongs to Phase 1 after real content is supplied.

## Acceptance gate for Phase 3

Phase 3 must not start until the following are true:

- Three coordinated real hero media candidates are approved.
- Their licensing/ownership status is recorded.
- Flagship project order is approved.
- Hero and flagship copy exists in TR and EN.
- Poster and fallback states can communicate the composition without motion.
- No placeholder image, generic AI portrait, invented metric, or invented client result is needed to complete the design.
- The preserved Lovable screenshot has been used only for hierarchy, atmosphere, and rhythm—not for source media, names, metrics, or contact details.
