## Preview policy map

- Posters render for every project; project images are lazy below the hero.
- A project video receives `src` only after pointer entry or keyboard focus and only when the existing policy allows playback.
- One shared module-level coordinator stops the previous project before a new preview starts.
- Blur, pointer leave, window blur, visibility loss, policy loss, unmount, and failed video all stop/reset playback.
- Coarse pointers, touch, reduced motion, save-data, or unsupported MP4 environments remain poster-led.
- Poster failure has a labeled CSS-backed fallback; video failure returns to the poster.
